# hwmusic · 华为音乐终端播放器

参考 go-musicfox 的键盘操作方式，复用hwmusic的华为音乐协议、歌词和原生音频模块。
终端界面使用 Bubble Tea，不加载 Viva，不需要 DISPLAY、XWayland、Vulkan 或 Node.js 运行时。
Linux 播放需要可用的 PulseAudio/PipeWire 或 ALSA 音频设备。

## 使用

```sh
hwmusic
```

首次启动按 **大写 L**，在独立浏览器窗口用自己的华为账号扫码；授权后窗口关闭，自动回到终端。
后续启动会校验并恢复终端版保存的音乐会话，无需打开桌面播放器。
会话失效后需重新扫码；不会自动续期。
登录需要 Chrome/Chromium/Edge，必要时指定 `HWMUSIC_AUTH_BROWSER=/绝对路径/浏览器 hwmusic`。

使用自己的账号权益播放华为音乐源；本项目非官方，OAuth 身份不属于本项目。
不提供音频下载、解密、其他平台音源或会员限制绕过。

| 按键 | 操作 |
| --- | --- |
| `1` / `2` / `3` / `4` | 收藏 / 歌单 / 历史 / 播放队列 |
| `↑` / `↓` 或 `k` / `j` | 选择歌曲；接近末尾自动翻页 |
| `Enter` | 播放选中项；收藏/歌单使用当前已载入列表，搜索/历史将选中歌曲加入队列 |
| `P` | 完整读取收藏或歌单的所有分页后连续播放；`Esc` 可取消 |
| `a` | 选中歌曲加入队尾，不打断当前播放 |
| `Space` | 暂停 / 继续 |
| `n` / `p` | 下一首 / 上一首 |
| `←` / `→` 或 `h` / `l` | 快退 / 快进 5 秒 |
| `+` / `-` | 音量 |
| `/` | 搜索，支持中文输入；Enter 提交、Esc 取消、Ctrl+U 清空 |
| `J` / `r` | 加载下一页 / 刷新当前列表 |
| `m` / `s` | 顺序、列表循环、单曲循环 / 随机 |
| `t` | 标准 / 无损音质，下首生效；受账号和资源权益限制 |
| `v` | 歌词视图 |
| `L` / `U` | 登录 / 退出账号并删除终端版保存的会话 |
| `?` | 快捷键帮助 |
| `q` / `Ctrl+C` | 保存队列和进度，停止音频并退出 |

在至少 42 列 × 16 行的终端运行，建议 100 × 30。恢复队列时不会自动发声，按空格继续。
终端退出即停止播放，不常驻后台。Linux 系统媒体控制通过独立 MPRIS 名称
`org.mpris.MediaPlayer2.hwmusic` 提供，不占用桌面版的名称。

## 配置与构建

终端版独立目录为 `${XDG_CONFIG_HOME:-$HOME/.config}/huawei-music-desktop/terminal-v1`。
凭据保存在仅当前用户可读的文件，密钥与密文同存，保护依赖系统用户隔离和文件权限。
不自动读取桌面版、旧 Electron 或 musicfox 的账号数据。可用 `--profile /绝对路径` 指定独立目录。

在源码根目录运行（Go 1.26.10+、C 编译器、Node.js 22.15+）：

```sh
npm run build:tui
npm run install:tui
```

可用 `HWMUSIC_GO=/绝对路径/go` 指定 Go。二进制和许可位于 `out/hwmusic/linux-x64`。
免编译安装：解压发布包，将 `hwmusic` 复制到 `~/.local/bin/` 并赋予执行权限。
删除 `~/.local/bin/hwmusic` 和 `~/.local/share/hwmusic` 即卸载程序；配置另行保留。

## 离线检查与验收范围

```sh
hwmusic --demo
hwmusic --demo --fixture-dir /绝对路径/合成音频目录
```

演示只展示合成曲库，不读取任何账号或请求音乐网络。音频目录应包含自行生成的
`tone.mp3` 和 `tone.flac`，演示默认静音，可按 `+` 调整音量。
不要把私人媒体当作合成夹具。

已在 Ubuntu 26.04.1 x86_64 验证：无 DISPLAY 的伪终端启动、键盘操作和中文搜索输入，
合成 MP3/FLAC 播放、暂停、跳转、自动切歌及退出；离线状态测试、race、vet，
既有 Chrome 合成回调和隔离 MPRIS 测试通过。真实账号扫码、在线曲库、在线播放及
不同账号权限须由当前用户登录验收，合成测试不代表这些已经成功。
